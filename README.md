# D9 Harlem Votes™ — Voter Registration Conversation Cards

Web home for the nine D9 Harlem Votes™ Community Conversation Cards.

**Live site:** https://d9harlemvotes.github.io/cards/

Each card has its own URL (`/card1/` through `/card9/`) for per-card QR analytics
via GoatCounter. Card numbering is intentionally generic so the deck can be
reordered or updated without breaking printed QR codes.

D9 Harlem Votes™ is a nonpartisan civic education coalition comprised of members
of historically Black fraternities and sororities serving Harlem, New York.
